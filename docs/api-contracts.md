# API Contracts

Base URL (Server): `http://localhost:5000`
Base URL (AI Engine): `http://localhost:8000`

All `/api/*` endpoints except `/api/auth/*` require:
```
Authorization: Bearer <jwt>
```

---

## Auth

### POST /api/auth/login
Request:
```json
{ "username": "admin", "password": "admin123" }
```
Response (OTP required):
```json
{ "requireOtp": true, "userId": "..." }
```
Response (direct login fallback):
```json
{ "token": "jwt...", "user": { "username": "admin", "role": "admin" } }
```

### POST /api/auth/verify-otp
Request:
```json
{ "userId": "...", "otpCode": "123456" }
```
Response:
```json
{ "token": "jwt...", "user": { "username": "admin", "role": "admin" } }
```

### POST /api/auth/google-login
Request:
```json
{ "access_token": "google_access_token_here..." }
```
Response:
```json
{ "token": "jwt...", "user": { "username": "john_123", "role": "operator" } }
```

### POST /api/auth/signup
Request:
```json
{ "username": "operator1", "email": "op@guardiansync.io", "password": "...", "role": "operator" }
```
Response:
```json
{ "message": "User created successfully" }
```

### GET /api/auth/me
Response:
```json
{ "id": "...", "username": "admin", "email": "admin@guardiansync.io", "role": "admin" }
```

## AI Engine (FastAPI — port 8000)

### POST /predict
Runs anomaly detection on a command's sensor parameters.

Request:
```json
{
  "command": "OVERRIDE_SAFETY",
  "target_machine": "boiler-01",
  "industry": "power_plant",
  "parameters": { "temperature": 45.2, "pressure": 120.5, ... }
}
```
Response:
```json
{
  "action": "BLOCK",
  "anomaly_score": 0.9612,
  "confidence": 0.961,
  "explanation": "⚠️ CRITICAL ANOMALY DETECTED — ...",
  "flagged_features": [...],
  "timestamp": "2026-07-16T09:10:28Z",
  "command": "OVERRIDE_SAFETY",
  "target_machine": "boiler-01"
}
```

### POST /train
Generates synthetic training data, trains the IsolationForest + MLP ensemble, and saves all model artifacts to `ai-engine/models/`.

Response:
```json
{
  "status": "success",
  "message": "Model trained on 2400 normal samples",
  "samples_used": 2900,
  "model_path": ".../ai-engine/models/anomaly_detector.pkl",
  "true_positives": 456,
  "false_positives": 288,
  "false_negatives": 44
}
```

### POST /simulate
Request:
```json
{ "industry": "power_plant", "mode": "normal|attack", "count": 10 }
```

### GET /health
Response:
```json
{ "status": "ok", "model_loaded": true, "version": "1.0.0" }
```

### GET /industries
Returns all supported industry profiles with machine lists and available commands.

## Socket.io Events

The client subscribes to these events for real-time updates:

| Event | Description |
|---|---|
| `packet:new` | New SCADA packet generated by simulator |
| `packet:analyzed` | AI-enriched packet with anomaly score |
| `command:result` | Command decision returned (approved/blocked/pending) |
| `command:approved` | Pending command manually approved by admin |
| `command:rejected` | Pending command manually rejected by admin |
| `alert:new` | New anomaly alert created |
| `alerts:summary` | Alert count summary |
| `approval:new` | New command waiting for admin approval |
| `killswitch:changed` | Kill switch toggled on/off |
| `maintenance:changed` | Maintenance window toggled |
| `industry:changed` | Active simulation industry changed |
| `commands:expired` | Pending commands that exceeded their TTL |
